# Drum Samples

These real one-shot drum samples replace the fallback synthesized drums.

Current files:

- `kick.mp3`
- `snare.mp3`
- `hihat.mp3`
- `hihat-heavy.mp3`
- `tom-low.mp3`
- `tom-mid.mp3`
- `tom-high.mp3`
- `crash.mp3`

Source: Michael Fischer's Roland TR-808 sample set, mirrored by `tidalcycles/sounds-tr808-fischer`.

License: CC0 1.0 Universal.

Original files used:

- `bd8/BD5050.WAV` -> `kick.mp3`
- `sd8/SD5050.WAV` -> `snare.mp3`
- `ch8/CH.WAV` -> `hihat.mp3`
- `oh8/OH50.WAV` -> `hihat-heavy.mp3`
- `lt8/LT50.WAV` -> `tom-low.mp3`
- `mt8/MT50.WAV` -> `tom-mid.mp3`
- `ht8/HT50.WAV` -> `tom-high.mp3`
- `cy8/CY5050.WAV` -> `crash.mp3`

If any file is removed or still loading, Driftone falls back to the built-in synthesized drum sound.
